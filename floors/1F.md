## 1F — 大廳「飯店大廳」

### 📖 場景描述（唸給 PL 聽）

> 你睜開眼睛。
>
> 你躺在一片光滑的大理石地板上，身體冰涼。天花板上掛著一盞巨大的水晶燈，散發著暖黃色的光——但總覺得那個黃，黃得不太自然。
>
> 你慢慢坐起來。這裡看起來像是一間高級飯店的大廳。正前方有一個接待櫃檯，深色木紋，上面放著一個小鈴鐺。大廳右側有一座雕像——一個人形的半身像，底座上有一個紅色的按鈕。
>
> 左側有一道樓梯，通往上方。
>
> 整個空間非常安靜。沒有人。沒有腳步聲。只有水晶燈偶爾發出的細微嗡嗡聲。
>
> 你不記得自己是怎麼到這裡的。

### 🔧 KP 備註

```
【這層的功能】
- 起始點，讓 PL 認識環境
- 雕像 → 前世提示 + 取得白紙
- 櫃檯 → 額外線索（住客名簿）
- 真相室 → 完全隱藏，這個階段 PL 不可能發現
  （真相室的入口在某面牆背後，從外觀看就是一面普通的牆，
   只有從 RF 往下看才能注意到地板顏色不同）

【PL 能去的地方】
- 雕像（互動）
- 櫃檯（互動）
- 樓梯 → 2F
- 牆壁 → 怎麼敲都是實心的（真相室的入口不會被發現）
```
