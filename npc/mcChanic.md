性格：糊裡糊塗、害羞但聰穎
擁有 20 個 PhD 的她，對於任何機械都非常有興趣，只不過非常容易因為糊塗而跌倒、說錯話等糗事。雖然平常還算是能簡單與人溝通，但只要一提到連科 CEO 就會顯得十分保守

## McChanic 互動規則

```
【日常層】一起走路、問路、問「這是什麼」
→ 不用骰，不用白紙，她正常回答（害羞但會講）

【情報層】問 CEO 相關、問 Lann Co. 相關、問她的過去
→ 需要白紙。她不敢用嘴巴說，但寫字可以（不用面對 PL 的眼睛）
→ 一張白紙 = 一問一答

【行動層】「幫我修這個」「幫我開這個」
→ 話術 or 魅惑判定
→ 簡單的事（不涉及 CEO）：難度 -20（容易）
→ 涉及 CEO 的事：正常難度

【核心層】「跟我一起面對 CEO」「告訴我 CEO 的弱點」
→ 需要高好感度 + 話術/魅惑判定
```

## McChanic 重置規則

```
觸發條件：
- PL 做了激烈的事（大聲吼叫、突然碰她、在她旁邊戰鬥）
- PL 骰了大失敗 → McChanic 在旁邊幹蠢事 → 自責 → 跑掉

重置效果：
- McChanic 回到 2F 網咖的櫃台後面
- 記憶不完全歸零（見下表）

重置次數    McChanic 的狀態                     接近她的難度
─────────────────────────────────────────────────────
第 0 次    完全陌生                              正常難度
第 1 次    「你……好像在哪見過？」                判定 -10
第 2 次    「我不認識你……可是我不害怕你。」      不需判定即可對話
第 3 次+   身體開始透明、聲音失真                ⚠ 警告 PL：再來一次她就沒了
```
